# Mobi Studio 1.0.0

Canvas e Visualization Engine estritamente read-only. O produto deriva Scene Graph, renderiza por contexto gráfico desacoplado, oferece câmera determinística, seleção visual e painéis sem formulários ou ações de escrita.

Validação: `npx tsc -p mobi-products/mobi-studio/tsconfig.json --noEmit` e `npx vitest run --coverage --config mobi-products/mobi-studio/vitest.config.ts`.
