# Mobi Studio Technical Points

Phase 3.3 architectural technical infrastructure. Technical Points reuse environment-level `Infrastructure` and require `hostId` to reference a Wall, Floor, or Ceiling Architecture.

Supported kinds: outlets, switches, lighting, cold/hot water, sewer, gas, internet, TV, exhaust, drains, and custom points. No mobile synchronization, field capture, AI, server, or cloud behavior is included.
