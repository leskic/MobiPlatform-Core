# Mobi Studio Application v1

Aplicação headless de controle e edição da Plataforma Mobi. Consome a Foundation congelada, Presentation Core, Viewer 2.0, Transaction Engine, Origin, Copilot e Sync Manager.

Não contém renderização, geometria, servidor, persistência ou lógica de domínio.

Na raiz da Plataforma:

```bash
npm run build
npm test
npm run coverage
```
