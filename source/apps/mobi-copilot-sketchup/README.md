# Mobi Copilot SketchUp

Professional SketchUp 2026 plugin foundation for the Mobi Copilot assistant.

## Install For Human Test

Copy the `mobi_copilot` folder and `mobi_copilot.rb` loader into the SketchUp 2026 Plugins directory.

## Open

SketchUp menu:

`Extensions -> Mobi Copilot -> Abrir Painel`

The panel opens as a side dashboard with project, statistics, selection, events, and navigation buttons.
