# Mobi Studio Walls

Products Layer Fase 3.1. Paredes reutilizam `Architecture(type="wall")`. Segmentos usam `position` como início, `referencePlane` como fim, `size.width` como comprimento, `size.height` como altura e `size.depth` como espessura. Toda persistência passa pelo `MobiStudioApplication` e `TransactionCoordinator`.
