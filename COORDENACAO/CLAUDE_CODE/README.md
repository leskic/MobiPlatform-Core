# Pasta do Claude Code

Relatórios de handoff e implementação gerados pelo Claude Code ficam aqui,
versionados junto com o código.

Convenção de nome de arquivo sugerida:

```
COORDENACAO/CLAUDE_CODE/<BRANCH_OU_CHECKPOINT>_HANDOFF.md
```

Ao commitar um handoff aqui, atualize também `COORDENACAO/STATUS.md` no
mesmo commit.
