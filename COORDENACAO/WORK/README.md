# Pasta do Work

Relatórios de handoff e entrega gerados pelo Work ficam aqui, versionados
junto com o código (em vez de só como zip solto fora do repositório).

Convenção de nome de arquivo sugerida:

```
COORDENACAO/WORK/<BRANCH_OU_CHECKPOINT>_HANDOFF.md
```

Ao commitar um handoff aqui, atualize também `COORDENACAO/STATUS.md` no
mesmo commit.
